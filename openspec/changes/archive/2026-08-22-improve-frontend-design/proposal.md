## Why
The current frontend UI needs visual polish to appear more modern, professional, and visually pleasing. A well-designed user interface increases user trust and engagement. By drawing inspiration from existing, top-tier CMS platform designs, we will overhaul the aesthetics to create a more compelling and intuitive experience while remaining strictly within the FlyonUI design system.

## What Changes
- Overall layout and visual hierarchy improvements across the CMS dashboard.
- More consistent and intentional use of FlyonUI semantic classes (e.g., `card`, `btn`, `navbar`) instead of ad-hoc utilities.
- Introduction of modern web design principles (enhanced typography, sleek dark mode support, subtle micro-animations for interactions).
- Polish to interactive components, ensuring appropriate use of JavaScript plugins and data attributes from FlyonUI for a responsive feel.

## Capabilities
### New Capabilities
None.

### Modified Capabilities
None.

*(Note: This is a pure design/aesthetics overhaul. No specification-level functional capabilities are modified, hence `skip_specs: true` is set.)*

## Impact
- Only frontend presentation layers (React components, layouts, pages, CSS) are modified.
- No backend API, schema, or database query changes.
